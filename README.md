## 👩‍💻 Sobre mim

Sou apaixonada por qualidade de software e acredito que **bons testes são essenciais para entregar produtos confiáveis e escaláveis**.

Atualmente estudo e aplico práticas de **QA com foco em automação de testes** usando ferramentas como **Cypress**, além de explorar o uso de **Faker.js** para tornar os testes mais dinâmicos e realistas.  

Tive uma experiência marcante no **Bootcamp de Quality Assurance promovido pelo Atlântico Avanti e Softex**, onde pude fortalecer meus conhecimentos com base em desafios práticos e boas práticas do mercado.
